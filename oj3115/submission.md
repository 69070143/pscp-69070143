# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
ให้หาว่า ในเวลาที่เดินผ่านแต่ละช่วง จะมีร้านที่ยังเปิดอยู่กี่ร้าน
input:
รับค่า n จำนวนร้าน และ k จำนวนช่วงเวลาที่ต้องการเช็ค
รับค่า เวลาเปิดและปิดของแต่ละร้าน จำนวน n ร้าน
รับค่า ช่วงเวลาที่ต้องการเช็ค ตามจำนวน k

output:
แสดงผลจำนวนร้านที่เปิดอยู่ในช่วงเวลาที่ตรวจสอบแต่ละค่า โดยพิมพ์ต่อกันในบรรทัดเดียวคั่นด้วยช่องว่าง
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่าข้อมูลบรรทัดแรก โดยเก็บเป็น List และแยกข้อมูลด้วย .split() เพื่อนำค่าตัวแรกมาใช้กำหนดจำนวนช่วงเวลา
Step 2: กำหนดให้ n = int(text1[0]) เป็นจำนวนช่วงเวลาทั้งหมด
Step 3: กำหนดให้ check = [] เพื่อใช้เก็บรายการช่วงเวลาเริ่มต้นและสิ้นสุดของแต่ละช่วง
Step 4: ใช้คำสั่ง for _ in range(n): เพื่อวนรับค่าช่วงเวลาตามจำนวน n รอบ
Step 5: รับค่าข้อมูลช่วงเวลา (text2) ของแต่ละรอบ โดยเก็บเป็น List และแยกข้อมูลด้วย .split()
Step 6: กำหนดให้ start = int(text2[0]) เป็นจุดเริ่มต้นของช่วงเวลา
Step 7: กำหนดให้ stop = int(text2[1]) เป็นจุดสิ้นสุดของช่วงเวลา
Step 8: เพิ่ม tuple ของช่วงเวลา (start, stop) เข้าไปเก็บไว้ในลิสต์ check ด้วยคำสั่ง check.append((start, stop))
Step 9: รับค่าชุดเวลาที่ต้องการตรวจสอบ (check_times) โดยเก็บเป็น List และแยกข้อมูลด้วย .split()
Step 10: กำหนดให้ ans = [] เพื่อใช้เก็บผลลัพธ์จำนวนช่วงเวลาที่ทับซ้อนกันของแต่ละเวลาที่ตรวจสอบ
Step 11: ใช้คำสั่ง for time_str in check_times: เพื่อวนลูปทีละค่าเวลาที่ตรวจสอบ
Step 12: กำหนดให้ target = int(time_str) แปลงค่าเวลาที่กำลังตรวจสอบให้เป็นจำนวนเต็ม
Step 13: กำหนดให้ store_count = 0 เพื่อใช้นับจำนวนช่วงเวลาที่ครอบคลุมค่า target
Step 14: ใช้คำสั่ง for start, stop in check: เพื่อวนตรวจสอบกับทุกๆ ช่วงเวลาที่เก็บบันทึกไว้
Step 15: ตรวจสอบเงื่อนไขว่าค่า target อยู่ในช่วงเวลาดังกล่าวหรือไม่ ด้วยคำสั่ง if start <= target <= stop:
Step 16: หากเงื่อนไขเป็นจริง ให้เพิ่มค่าตัวนับ store_count ทีละ 1 ด้วย store_count += 1
Step 17: แปลงค่าผลลัพธ์ store_count ให้เป็น String และเพิ่มเข้าไปในลิสต์ ans ด้วย ans.append(str(store_count))
Step 18: แสดงผลค่าในลิสต์ ans ทั้งหมด โดยคั่นแต่ละค่าด้วยช่องว่างด้วยคำสั่ง print(" ".join(ans))

ก่อนถามเอไอ ฉันยังไม่แน่ใจว่าคำตอบที่แสดงออกมาคิดผิดที่ขั้นตอนไหน
```

## 4. วิธีสุดท้ายที่ใช้จริง

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

- อธิบายความหมายของโจทย์

- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

- คัดลอก code ของผู้อื่น
